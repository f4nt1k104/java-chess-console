# Архитектура Java Chess

## Слои

```text
┌─────────────────────────────┐
│ Main                        │
│  └── ConsoleGame (UI/ввод)  │
├─────────────────────────────┤
│ ChessGame (правила партии)  │
│  ├── статус / очередь хода  │
│  ├── проверка ходов         │
│  ├── рокировка / взятие     │
│  ├── мат / пат / ничья      │
│  └── история / FEN          │
├─────────────────────────────┤
│ Board (состояние и атаки)   │
│  └── Piece[8][8]            │
├─────────────────────────────┤
│ Piece + 6 подклассов        │
│ Position, Move, enums       │
└─────────────────────────────┘
```

- `Position`: неизменяемые координаты, проверка границ, разбор нотации `e4`.
- `Move`: неизменяемый ход, разбор `e2e4` или `e7e8q`.
- `Piece`: абстрактный класс, хранящий цвет и флаг первого хода. Наследники реализуют геометрию своих ходов.
- `Board`: массив 8×8, размещение фигур, поиск атакованных клеток и шаха. Возвращаемая извне доска копируется.
- `ChessGame`: проверка очередности, препятствий, специальных правил и безопасности короля. Учитывает статус игры, историю и повторения.
- `ConsoleGame`: обработка команд и печать доски; шахматная логика отсутствует.

## Порядок проверки хода

1. Проверка, что партия активна, ходит правильный игрок, на исходной клетке есть фигура.
2. Проверка геометрии хода полиморфным `Piece.isValidMove()`; для рокировки — отдельный путь.
3. Проверка препятствий и взятия, в том числе взятия на проходе.
4. Применение хода к **копии** `Board`.
5. Проверка, что собственный король не находится под шахом после предполагаемого хода.
6. Замена доски, обновление очередности, en passant, счётчиков и истории.
7. Поиск доступных ходов нового игрока. Если их нет: мат при шахе, иначе пат.
8. Проверка других оснований для ничьей.

## Особые правила

- **Рокировка:** король и соответствующая ладья не ходили; между ними пусто; король не под шахом и не пересекает атакованные клетки.
- **Взятие на проходе:** поле `enPassantTarget` сохраняется только после хода пешки на две клетки и очищается после следующего хода.
- **Превращение:** на последней горизонтали пешка заменяется новой фигурой (`Q/R/B/N`). Если тип не указан, выбирается ферзь.
- **Повторение позиции:** ключ содержит положение фигур, сторону хода, права рокировки и доступное поле en passant. При третьем появлении позиции игра завершается ничьёй.
- **Недостаточный материал:** распознаются K vs K, K+B vs K, K+N vs K и случаи, когда все оставшиеся слоны находятся на полях одного цвета.

## Осознанные ограничения

Это проект консольной партии между двумя людьми, не шахматный движок и не онлайн-сервис. Упрощён порядок объявления ничьих (автоматическое завершение по трёхкратному повторению и 50-ходовому правилу). Не реализованы часы, импорт FEN, PGN, оценка позиции и искусственный интеллект.
